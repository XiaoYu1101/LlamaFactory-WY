# JSON 场景改造测试报告

日期：2026-09-09。

## 改造范围

从“场景标识直接作为单标签答案”调整为“参考完整 JSON 样例扩写训练记录”。新增 JSONL/JSON 数组解析、字段及可选标签约束、完整记录存储和审核、按原指令与答案导出，以及直接下载 JSON。前端提供场景配置、外部文件选择、解析预览、问句与答案展示、多标签编辑。

旧数据库采用添加字段的迁移，原有项目和导出保留。新场景参考样例仅保存在配置中，不自动计入训练样本。原有 LlamaFactory 训练算法和评测实现未修改。

- 每批最多两条参考样例、上下文不随历史产出累积。
- 编辑指令和多标签答案、状态重置、过期修订拒绝、删除和恢复。
- JSON 下载、已冻结版本不被后续修改影响、旧数据库兼容。

原有 66 项工作流、接口、Gradio 挂载和训练参数/状态桥接测试仍通过。

Ruff 检查通过。前端 TypeScript 检查和 Vite 生产构建通过。构建存在单个 JS 包体积提示，测试存在依赖弃用提示，无失败。

## 浏览器验证

使用无头 Microsoft Edge 和真实前端页面，连接临时工作区及明确标识为 `browser-qa-mock` 的模拟生成接口。

以用户的外部 `dam_intent.json` 文件执行：

1. 错误 JSON 显示校验错误并禁止保存。
2. 文件选择导入成功，识别 5 条完整 JSONL 样例、7 个答案标签。
3. 保存一个 `dam_intent` 场景，生成 20 条模拟记录。
4. 将问句修改，并将答案改为“数值查询、内容生成”；保存后待审核。
5. 删除、在回收站恢复、批量通过。
6. 保存数据版本，通过浏览器实际下载 JSON，检查 20 条完整记录、原 instruction、多标签 output，确认输出不是场景标识。
7. 浏览器没有 JavaScript 页面错误。

本机截图及下载检查文件位于 `workspace/qa-artifacts/`，不提交用户数据到源码仓库。模拟生成用于验证流程，不作为真实训练数据。
